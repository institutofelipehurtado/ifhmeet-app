# IFH Meet — páginas e versões

Repositório público do IFH Meet, aplicativo interno do Instituto Felipe Hurtado. O código fica num repositório privado; aqui ficam só:

- as páginas de início e de privacidade, publicadas pelo GitHub Pages em https://institutofelipehurtado.github.io/ifhmeet-app/ (usadas na tela de login do Google);
- os instaladores, nas Releases. O app procura atualização em `https://github.com/institutofelipehurtado/ifhmeet-app/releases/latest/download/` (`latest.yml`, o `.exe`, o `.blockmap` e a assinatura `.sig`).

Nada aqui pode ter segredo: tudo é público.
